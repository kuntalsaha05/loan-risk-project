# Project Plan

## Objective
Build a loan risk analysis and prediction system that is directly aligned with syllabus Units I-IV.

## Workflow Summary
1. Understand the dataset and identify data types.
2. Preprocess and engineer features.
3. Implement ETL flow.
4. Design a simple data warehouse with a star schema.
5. Apply association rule mining.
6. Train supervised learning models.
7. Perform K-Means clustering.
8. Build visualizations.
9. Implement the system modules.
10. Present the overall architecture in the report.

## Unit Mapping
- Unit I: data types, preprocessing, transformation, reduction
- Unit II: ETL, data warehouse, OLTP vs OLAP
- Unit III: association rules and pattern mining
- Unit IV: classification and clustering

## Key Outputs
- Cleaned dataset
- Processed dataset in database
- Warehouse schema
- Association rule results
- Classification models
- Clustering results
- Dashboard visualizations
- Final report
